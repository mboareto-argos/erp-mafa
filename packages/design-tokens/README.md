# @erp-mafa/design-tokens

Tokens do Design System (docs/product/design-system.md, seção 4) em formato consumível por
código. `tokens.json` é a fonte; mapeie para `theme.extend` do Tailwind em `apps/web`.

Regra: nenhum valor de cor/espaçamento/tipografia deve ser escrito solto no código da UI —
sempre referenciar um token daqui.
