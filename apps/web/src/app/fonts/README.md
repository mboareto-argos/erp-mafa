# Fontes locais

Estas fontes são carregadas por `next/font/local` em `../layout.tsx`, para que
`next build` com Turbopack não dependa de acesso ao Google Fonts.

- Inter, pesos 400, 600 e 700 — [SIL Open Font License 1.1](https://github.com/rsms/inter/blob/master/LICENSE.txt)
- JetBrains Mono, pesos 400 e 600 — [SIL Open Font License 1.1](https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt)

Os arquivos foram obtidos das distribuições públicas do Google Fonts em
2026-08-05. Ao atualizar uma fonte, atualizar os pesos neste diretório e a
configuração correspondente em `layout.tsx`.
